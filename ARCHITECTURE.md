# FitAgent — Technical Architecture

---

## Tech Stack
- **Frontend:** React + Vite
- **Styling:** TailwindCSS
- **Database + Auth:** Supabase
- **AI:** Anthropic Claude API
- **Deployment:** Vercel
- **Payments:** Stripe
- **PWA:** manifest.json + service worker

## Claude API Layer — claude.js

### buildContextBrief(userId)
- Fetches profile, memory, recent sessions from Supabase
- Constructs the intelligence brief string
- Returns formatted context ready for prompt injection

### routeModel(messageType)
- 'chat' | 'question' → claude-haiku-4-5
- 'program' | 'checkin' | 'analysis' → claude-sonnet-4-6

### callClaude(message, userId, type)
1. buildContextBrief(userId)
2. routeModel(type)
3. Construct full prompt (persona + brief + message)
4. Call Anthropic API
5. Parse response
6. Extract and persist any decisions or signals
7. Return response to UI

---

## System Prompt Structure

Every API call constructs a prompt in this order:

```
[Coaching persona and tone instructions]
[User intelligence brief — profile + memory]
[Current program]
[Response format instructions]
[Web search guidance — when to use it]
```

## Gym Mode State Machine

```
IDLE
  → user taps "I'm at the gym"
CONFIRM_WEIGHT
  → confirm or update weights for today
SET_ACTIVE
  → display exercise + target
  → user taps reps completed
REST
  → rest timer counts down
  → auto-advance to next set
SESSION_COMPLETE
  → persist session to DB
  → trigger agent feedback
  → return to HOME
```

## Context Window Management

### Short term (months 1-3)
Send full session history — no optimization needed.

### Medium term (months 3-6)
- Last 4 weeks: full session detail
- Older history: compressed summary (generated by Claude monthly)

### Summary generation prompt
Run monthly per active user:
"Summarize this user's training history older than
4 weeks into 2-3 sentences capturing PRs, patterns,
recurring issues, and notable progress."

## Cost Control

### Model routing saves ~70% on casual interactions
### Prompt caching on system prompt + profile
### Rate limiting
- Free tier: 20 lifetime interactions hard cap
- Paid tier: 50 interactions per day soft cap
  (invisible to normal users, protects against abuse)
### Monitoring
- Log tokens_used per interaction to interactions table
- Alert if single user exceeds 1000 tokens/day average
